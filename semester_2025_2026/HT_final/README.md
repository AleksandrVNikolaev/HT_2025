# Итоговое задание №13 — Сетевое взаимодействие

Описание
Проект реализует парсер данных Росреестра.  
Пользователь вводит кадастровый номер участка, а программа запрашивает информацию напрямую с сайта **pkk.rosreestr.ru**.

## Технологии
- Python 3.11+
- `requests`
- `json`
- `decimal`
- `pathlib`
- Сериализация/десериализация в JSON (методы `to_dict` / `from_dict`)

## Запуск
```bash
python parser_rosreestr.py
